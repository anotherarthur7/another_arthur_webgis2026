Проект на Django для создания заявки пользователями на создание точек интереса, необходимые в зоне логистической доступности.

Пример workflow: пользователь нуждается в точке быстрого питания -> расставляет по карте точки, где ему хотелось бы видеть точку интереса -> заявки пользователей суммируются в тепловую карту по контексту -> данные передаются бизнесу или учреждениям, способным удовлетворить запрос пользователей.
